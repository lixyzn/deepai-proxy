# Logos de fabricantes

Ícones SVG locais usados pelo painel para identificar a família do modelo. O
mapeamento fica em `public/app.js`; modelos sem uma família reconhecida usam as
iniciais do provedor como fallback.

- `anthropic.svg`, `chatglm.svg`, `deepai.svg`, `deepseek.svg`, `gemini.svg`,
  `kimi.svg`, `minimax.svg`, `openai.svg`, `qwen.svg`, `upstage.svg` e
  `zhipu.svg`: [LobeHub Icons](https://github.com/lobehub/lobe-icons), licença
  MIT do projeto de ícones.
- `xiaomi.svg`: [Simple Icons](https://github.com/simple-icons/simple-icons),
  licença CC0.

As marcas pertencem aos respectivos titulares. O uso dos ícones é apenas
identificativo; este projeto não é afiliado nem endossado por DeepAI, OpenAI,
Anthropic, Google, Xiaomi ou qualquer outro fabricante.
